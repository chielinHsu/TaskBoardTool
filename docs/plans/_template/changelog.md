# Rnn 變更紀錄

> 只新增，新紀錄放最上方；只記本計畫的事。每個 agent session 一筆。
> agent 欄位寫實際的工具與模型，不要從舊紀錄抄；沒有執行的檢查寫「未驗證」與原因，不可以寫「通過」。
> 動到別的計畫管的設計或介面時，在那個計畫的 `changelog.md` 另記一筆「受影響的內容」，兩邊互相連結。

## 格式

```markdown
## YYYY-MM-DD — Claude Code (模型) ／ Codex (模型)

### 細項
- Rnn.m：做了什麼（一行一件）

### 修改的檔案
- path/to/file

### 驗證
- 實際執行的指令與結果；沒執行就寫「未驗證」與原因

### Commit
- `<hash>` 標題（還沒 commit 就寫「未提交」）

### 注意事項
- 否決的做法、不要還原的修改、下一位要知道的限制
```
