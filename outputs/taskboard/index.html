Session 心智圖

卡片 → session → 每次對話。點 session 查看聊天紀錄，點對話跳到卡片詳情裡的那次回報；按 session 右側的 ＋／− 展開或收合。Ctrl＋滾輪或 ＋／− 鍵縮放，拖曳空白處平移，0 鍵符合寬度。Ctrl＋M 開啟／關閉心智圖（滑鼠指著的卡片或已開啟的卡片詳情）。

匯入計畫（功能展開 → 列管卡片）

貼上計畫 JSON：每個事項成為一張列管卡片；Claude Code 事項可用 role（fast-worker／developer／developer-deep／architect／architect-deep）自動對應模型與推理強度，或直接給 model／effort；dependsOn 以 key 指定前置事項，前置卡片全部驗收完成後自動排入待辦。也可在終端機執行 python outputs/taskboard/plan_import.py plan.json，或在 Claude Code 對話中請它呼叫看板工具 import_plan。

{"name":"深色模式","project":"網站","cwd":"C:\\repo","tool":"claude","items":[

 {"key":"css","title":"套用深色樣式","role":"developer-deep","dependsOn":["tokens"]},
 {"key":"docs","title":"更新文件","tool":"codex","dependsOn":["tokens"],"priority":"low"}]}
